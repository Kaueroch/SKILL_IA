# saas-ui

Skill autoral para construir SaaS UI moderna, não-genérica, com React + TypeScript + Tailwind v4 + shadcn/new-york.

## Quando usar

Use quando pedir landing page, dashboard, tela de app, componente, layout, pricing, onboarding, empty/loading/error state, tabela, dialog, sidebar, ou disser "SaaS design, UI, frontend, modern, clean, beautiful".

## Stack

- React + TypeScript strict
- Tailwind CSS v4 com `@theme`
- shadcn new-york em `components/ui/`
- `lucide-react` para ícones
- `next/font` para tipografia
